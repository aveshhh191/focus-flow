# FocusFlow — Student Task Manager (Updated)

A responsive student task manager made with HTML, CSS, and JavaScript.

## New in this version
- Choose an estimated duration for each task (15 minutes to 3 hours)
- See the planned time remaining for unfinished tasks
- Task history records completed, reopened, and deleted tasks with timestamps
- History is saved in browser localStorage and keeps the latest 100 activity entries
- Clear history without deleting current tasks

## Features
- Add tasks with priority
- Mark tasks complete or reopen them
- Delete tasks
- Filter all, to-do, and completed tasks
- Progress percentage and task statistics
- Responsive dark design for desktop and mobile
- Browser localStorage persistence

## Run
Extract the ZIP and open `index.html` in your browser, or open the folder in VS Code and use Live Server. No server or installation is required.

## Portfolio description
FocusFlow is a responsive student task management web app that helps students organize academic assignments, estimate the time needed for each task, and review their activity history. It includes priority levels, task filtering, progress tracking, and browser-based storage using localStorage.

## Technologies
HTML5, CSS3, JavaScript, DOM manipulation, events, arrays, localStorage.

## Learning outcomes
Semantic HTML, responsive layouts, JavaScript event handling, DOM updates, array filtering, data persistence, and activity logging.

## Future improvements
Due dates, subject categories, reminders, data export, and optional cloud sync.
